Buka index.html untuk tampilan utama atau bootstrap.html untuk tampilan Bootstrap.
HTML, CSS, dan JavaScript dipisahkan agar mudah disunting.
Untuk menjalankan melalui server lokal: buka terminal di folder ini lalu jalankan python -m http.server 8000, dan kunjungi http://localhost:8000.
Bootstrap memakai CSS 5.3.8 dari CDN sehingga versi Bootstrap memerlukan koneksi internet.
Input tersimpan di localStorage browser; belum ada database, login, atau penyimpanan terpusat.
